Streamify is a real-time language learning platform where users can connect with people around the world and practice new languages through **chat and video calls**.

The goal of Streamify is to make language learning **interactive, social, and practical** by allowing users to communicate directly with other learners.

---

## 🚀 Features

* 💬 Real-time chat with users
* 📹 Video calling for live conversation practice
* 🌐 Connect with people who speak different languages
* 🔐 Secure authentication system
* 👤 User profile and language preferences
* ⚡ Fast and responsive user interface
* 📱 Works across modern browsers

---

## 🧠 How It Works

1. User creates an account or logs in.
2. Users can find other people who want to learn or teach languages.
3. They can start a **chat conversation**.
4. They can switch to a **video call** for real-time speaking practice.
5. This helps improve language skills through real communication.

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/streamify.git
```

Go to the project directory:

```bash
cd streamify
```

Install dependencies:

```bash
npm install
```

Run the project:

```bash
npm start
```

---

## 🌐 Environment Variables

Create a `.env` file in the backend and add:

```
PORT=3000
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
STREAM_API_KEY=your_stream_api_key
STREAM_SECRET=your_stream_secret
```
